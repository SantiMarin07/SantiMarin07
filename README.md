### Sobre mí

Trabajo como analista de mesa de ayuda y construyo productos web en mi tiempo libre. Soy estudiante de ingeniería en la Universidad de Cundinamarca, donde hice mi primera app completa: un sistema de préstamo de equipos, primero en React y luego en Android con Java y MySQL.

Hoy me enfoco en **React** y en **experiencias 3D para la web con Three.js**. Busco mi primer rol como desarrollador junior y tomo proyectos freelance bajo la marca **smdevc**.
